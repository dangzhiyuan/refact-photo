## 2. 核心概念与设计模式

### 2.1 命令模式

命令模式是整个架构的基础，用于封装所有编辑操作，支持撤销/重做功能。

```typescript
// 命令接口
export interface Command {
  execute(): void; // 执行命令
  undo(): void; // 撤销命令
  redo?(): void; // 重新执行命令（可选，默认调用execute）

  // 元数据
  name: string; // 命令名称，用于历史记录
  timestamp: number; // 命令执行时间戳
}

// 命令管理器
export class CommandManager {
  private history: Command[] = []; // 历史记录
  private currentIndex: number = -1; // 当前命令索引

  // 执行新命令
  execute(command: Command): void {
    // 截断历史记录（如果当前不是最新）
    if (this.currentIndex < this.history.length - 1) {
      this.history = this.history.slice(0, this.currentIndex + 1);
    }

    // 执行命令
    command.execute();

    // 添加到历史记录
    this.history.push(command);
    this.currentIndex++;

    // 通知UI更新
    this.notifyHistoryChanged();
  }

  // 撤销命令
  undo(): void {
    if (this.canUndo()) {
      this.history[this.currentIndex].undo();
      this.currentIndex--;
      this.notifyHistoryChanged();
    }
  }

  // 重做命令
  redo(): void {
    if (this.canRedo()) {
      this.currentIndex++;
      const command = this.history[this.currentIndex];
      if (command.redo) {
        command.redo();
      } else {
        command.execute();
      }
      this.notifyHistoryChanged();
    }
  }

  // 检查是否可以撤销
  canUndo(): boolean {
    return this.currentIndex >= 0;
  }

  // 检查是否可以重做
  canRedo(): boolean {
    return this.currentIndex < this.history.length - 1;
  }

  // 获取历史记录
  getHistory(): Command[] {
    return this.history;
  }

  // 获取当前索引
  getCurrentIndex(): number {
    return this.currentIndex;
  }

  // 通知历史变化
  private notifyHistoryChanged(): void {
    // 发布事件
    EventEmitter.emit("historyChanged", {
      canUndo: this.canUndo(),
      canRedo: this.canRedo(),
      historyLength: this.history.length,
      currentIndex: this.currentIndex,
    });
  }
}
```

### 2.3 临时状态与持久状态分离

将交互过程中的临时状态与最终持久状态分离，实现流畅的实时反馈。

```typescript
// 定义临时交互状态
interface InteractionState {
  // 当前活动图层
  activeLayerId: string | null;

  // 拖动状态
  isDragging: boolean;
  dragStartPosition: Point | null;

  // 缩放状态
  isScaling: boolean;
  scaleStartValue: number | null;

  // 旋转状态
  isRotating: boolean;
  rotationStartValue: number | null;

  // 临时变换预览
  previewTransforms: Map<
    string,
    {
      position?: Point;
      scale?: number;
      rotation?: number;
    }
  >;

  // 其他临时状态...
}

// 交互状态仓库
export const useInteractionStore = create<
  InteractionState & InteractionActions
>((set, get) => ({
  // 初始状态
  activeLayerId: null,
  isDragging: false,
  isScaling: false,
  isRotating: false,
  dragStartPosition: null,
  scaleStartValue: null,
  rotationStartValue: null,
  previewTransforms: new Map(),

  // 更新方法
  setActiveLayer: (id) => set({ activeLayerId: id }),

  // 开始拖动
  startDrag: (layerId, position) => {
    set({
      activeLayerId: layerId,
      isDragging: true,
      dragStartPosition: position,
    });
  },

  // 更新预览变换
  updatePreviewTransform: (layerId, transform) => {
    set((state) => {
      const previewTransforms = new Map(state.previewTransforms);

      // 获取现有预览或创建新预览
      const existingPreview = previewTransforms.get(layerId) || {};

      // 合并新变换
      previewTransforms.set(layerId, {
        ...existingPreview,
        ...transform,
      });

      return { previewTransforms };
    });
  },

  // 结束交互，清理临时状态
  endInteraction: () => {
    set({
      isDragging: false,
      isScaling: false,
      isRotating: false,
      dragStartPosition: null,
      scaleStartValue: null,
      rotationStartValue: null,
      previewTransforms: new Map(),
    });
  },
}));
```

## 3. 状态管理与数据流

### 3.1 状态划分

将应用状态分为三个主要部分：

1. **文档状态** - 持久化的编辑内容（图层、滤镜等）
2. **交互状态** - 临时的用户交互状态（拖动、缩放等）
3. **应用状态** - 用户界面状态（工具选择、面板打开等）

### 3.2 单向数据流

采用单向数据流模式，确保状态更新的可预测性：

```
用户交互 → 创建命令 → 执行命令 → 更新持久状态 → 视图渲染
   ↑                                    |
   └────────────────────────────────────┘
            (实时预览反馈)
```

#### 4.1.1 常见命令实现

```typescript
// 添加图层命令
export class AddLayerCommand implements Command {
  name = "添加图层";
  timestamp = Date.now();
  private layerId: string;

  constructor(private layer: Layer) {
    this.layerId = layer.id;
  }

  execute() {
    useDocumentStore.getState().addLayer(this.layer);
  }

  undo() {
    useDocumentStore.getState().removeLayer(this.layerId);
  }
}

// 移动图层命令
export class MoveLayerCommand implements Command {
  name = "移动图层";
  timestamp = Date.now();

  constructor(
    private layerId: string,
    private oldPosition: Point,
    private newPosition: Point
  ) {}

  execute() {
    useDocumentStore.getState().moveLayer(this.layerId, this.newPosition);
  }

  undo() {
    useDocumentStore.getState().moveLayer(this.layerId, this.oldPosition);
  }
}

// 应用滤镜命令
export class ApplyFilterCommand implements Command {
  name = "应用滤镜";
  timestamp = Date.now();
  private previousFilter: { type: string; intensity: number };

  constructor(
    private layerId: string,
    private filterType: string,
    private intensity: number
  ) {
    // 保存先前状态
    const layer = useDocumentStore.getState().layers.get(layerId) as ImageLayer;
    this.previousFilter = {
      type: layer.filterType,
      intensity: layer.filterIntensity,
    };
  }

  execute() {
    useDocumentStore.getState().updateLayer(this.layerId, {
      filterType: this.filterType,
      filterIntensity: this.intensity,
    });
  }

  undo() {
    useDocumentStore.getState().updateLayer(this.layerId, {
      filterType: this.previousFilter.type,
      filterIntensity: this.previousFilter.intensity,
    });
  }
}
```

#### 4.1.2 复合命令（宏命令）

```typescript
// 复合命令（执行多个命令作为一个单元）
export class CompositeCommand implements Command {
  name: string;
  timestamp = Date.now();

  constructor(private commands: Command[], name?: string) {
    this.name = name || "组合操作";
  }

  execute() {
    this.commands.forEach((cmd) => cmd.execute());
  }

  undo() {
    // 反向遍历撤销
    for (let i = this.commands.length - 1; i >= 0; i--) {
      this.commands[i].undo();
    }
  }
}
```

#### 4.2.1 图层渲染器

```tsx
// 主渲染组件
export const DocumentRenderer: React.FC = () => {
  const { document, layers } = useDocumentStore();
  const { previewTransforms } = useInteractionStore();

  // 按Z-index排序的图层
  const sortedLayers = useMemo(() => {
    return Array.from(layers.values()).sort((a, b) => a.zIndex - b.zIndex);
  }, [layers]);

  return (
    <Canvas style={styles.canvas}>
      <Group>
        {sortedLayers.map((layer) => {
          // 检查是否有临时预览变换
          const previewTransform = previewTransforms.get(layer.id);

          // 计算实际使用的变换
          const effectiveTransform = {
            position: previewTransform?.position || layer.transform.position,
            scale: previewTransform?.scale || layer.transform.scale,
            rotation: previewTransform?.rotation || layer.transform.rotation,
          };

          // 根据图层类型渲染
          return (
            <LayerRenderer
              key={layer.id}
              layer={layer}
              transform={effectiveTransform}
            />
          );
        })}
      </Group>
    </Canvas>
  );
};

  transform: Transform;
```

### 4.3 手势系统

手势系统负责捕获和处理用户交互，将其转换为命令或临时状态更新。

#### 4.3.1 图层交互控制器

```tsx
// 图层手势管理器
export const LayerInteractionManager: React.FC = () => {
  const { layers } = useDocumentStore();
  const interactionState = useInteractionStore();
  const commandManager = useCommandManager();

  // 按Z-index排序的图层
  const sortedLayers = useMemo(() => {
    return Array.from(layers.values()).sort((a, b) => b.zIndex - a.zIndex); // 注意：这里是倒序，使顶层图层先被检测
  }, [layers]);

  // 拖动手势处理
  const dragGesture = Gesture.Pan()
    .onBegin((e) => {
      // 命中测试，找到最上层的被点击图层
      const point = { x: e.x, y: e.y };
      const hitLayer = sortedLayers.find(
        (layer) => layer.isVisible && layer.hitTest(point)
      );

      if (hitLayer) {
        // 记录起始状态
        interactionState.startDrag(hitLayer.id, hitLayer.transform.position);
      }
    })
    .onChange((e) => {
      const { activeLayerId, dragStartPosition } = interactionState;

      if (activeLayerId && dragStartPosition) {
        // 更新预览变换
        interactionState.updatePreviewTransform(activeLayerId, {
          position: {
            x: dragStartPosition.x + e.translationX,
            y: dragStartPosition.y + e.translationY,
          },
        });
      }
    })
    .onFinalize((e) => {
      const { activeLayerId, dragStartPosition, previewTransforms } =
        interactionState;

      if (activeLayerId && dragStartPosition) {
        const previewTransform = previewTransforms.get(activeLayerId);

        if (previewTransform?.position) {
          // 创建并执行移动命令
          const moveCommand = new MoveLayerCommand(
            activeLayerId,
            dragStartPosition,
            previewTransform.position
          );

          commandManager.execute(moveCommand);
        }
      }

      // 清理临时状态
      interactionState.endInteraction();
    });

  // 缩放手势处理
  const scaleGesture = Gesture.Pinch()
    .onBegin((e) => {
      // 类似逻辑...
    })
    .onChange((e) => {
      // 类似逻辑...
    })
    .onFinalize((e) => {
      // 类似逻辑...
    });

  // 旋转手势处理
  const rotateGesture = Gesture.Rotation()
    .onBegin((e) => {
      // 类似逻辑...
    })
    .onChange((e) => {
      // 类似逻辑...
    })
    .onFinalize((e) => {
      // 类似逻辑...
    });

  // 组合手势
  const combinedGesture = Gesture.Race(
    dragGesture,
    Gesture.Simultaneous(scaleGesture, rotateGesture)
  );

  return (
    <GestureDetector gesture={combinedGesture}>
      <View style={StyleSheet.absoluteFill} />
    </GestureDetector>
  );
};
```

## 5. 手势与渲染协同工作流程

### 5.1 拖动图层流程

```
1. 用户按下并拖动图层 →
2. GestureHandler 捕获 Pan 手势 →
3. onBegin 时执行命中测试，找到被点击的图层 →
4. 设置活动图层并记录起始位置 →
5. onChange 时更新临时预览变换 →
6. 渲染系统使用临时预览绘制图层 →
7. onFinalize 时创建并执行 MoveLayerCommand →
8. 命令更新持久状态 →
9. 清理临时预览状态
```

### 5.2 应用滤镜流程

```
1. 用户选择滤镜并调整强度 →
2. UI创建 ApplyFilterCommand →
3. 执行命令，更新图层的滤镜属性 →
4. 渲染系统应用滤镜效果 →
5. 命令被添加到历史记录
```

### 5.3 绘图流程

```
1. 用户激活绘图工具 →
2. 用户在画布上绘制 →
3. DrawingTool 创建路径并实时更新 →
4. 临时预览显示当前绘制内容 →
5. 用户释放时，创建并执行 AddDrawingCommand →
6. 命令创建新的绘图图层或添加路径到现有图层 →
7. 持久状态更新，渲染最终结果
```

## 7. 性能优化策略

### 7.1 渲染优化

1. **图层缓存**：对未修改的图层进行缓存渲染

   ```typescript
   // 图层缓存示例
   export class LayerCache {
     private cache: Map<
       string,
       {
         hash: string;
         image: SkImage;
       }
     > = new Map();

     // 获取缓存图像
     getCache(layer: Layer): SkImage | null {
       const entry = this.cache.get(layer.id);
       const hash = this.computeLayerHash(layer);

       if (entry && entry.hash === hash) {
         return entry.image;
       }

       return null;
     }

     // 添加到缓存
     addToCache(layer: Layer, image: SkImage): void {
       const hash = this.computeLayerHash(layer);
       this.cache.set(layer.id, { hash, image });
     }

     // 计算图层哈希（用于判断图层是否变化）
     private computeLayerHash(layer: Layer): string {
       // 为图层创建唯一哈希
       return JSON.stringify({
         transform: layer.transform,
         opacity: layer.opacity,
         blendMode: layer.blendMode,
         // 图层专有属性...
       });
     }
   }
   ```

2. **分块渲染**：仅渲染视口内的内容

3. **降低非活动内容的精度**：编辑时降低其他区域的渲染质量

### 7.2 交互优化

1. **节流与防抖**：限制状态更新频率

   ```typescript
   import { throttle } from "lodash";

   // 节流处理手势更新
   const updatePreviewThrottled = throttle((layerId, transform) => {
     interactionState.updatePreviewTransform(layerId, transform);
   }, 16); // 约60fps
   ```

2. **工作分离**：使用 requestAnimationFrame 或 useAnimationFrame 进行视觉更新

3. **惰性初始化**：按需加载资源和初始化组件

### 7.3 内存管理

1. **图像缩放**：处理大图片时自动缩放到合适尺寸

2. **资源释放**：不再需要的图像资源主动释放

3. **分级加载**：低分辨率预览和高分辨率编辑
