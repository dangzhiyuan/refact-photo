# 编辑器基础模块实现

编辑器基础模块是PhotoPixel应用的核心部分，负责提供用户界面和功能，让用户能够编辑和修饰选中的图片。该模块由以下几个主要部分组成：

## 模块概述

1. **主编辑器页面**：整合所有编辑功能的容器页面
2. **分类选项卡**：提供不同编辑类别（滤镜、涂鸦、贴纸、模板）的切换
3. **画布渲染系统**：显示和处理图像的核心组件
4. **编辑面板系统**：根据当前选中的编辑类别显示不同的编辑工具

  const [isInitializing, setIsInitializing] = useState(true);
  
  const { 
    activeCategoryId, 
    setActiveCategoryId,
    currentImageUri,
    setCurrentImageUri,
    isSaving,

  } = useEditorStore();

      const { status } = await MediaLibrary.requestPermissionsAsync();
      if (status !== 'granted') {
        Alert.alert('权限错误', '需要访问相册权限以保存图片');
        return;
      }
      
      // 保存到相册
      const asset = await MediaLibrary.createAssetAsync(currentImageUri);
      
      // 创建相册并添加图片（可选）
      // const album = await MediaLibrary.getAlbumAsync('PhotoPixel');
      // if (album === null) {
      //   await MediaLibrary.createAlbumAsync('PhotoPixel', asset, false);
      // } else {
      //   await MediaLibrary.addAssetsToAlbumAsync([asset], album, false);
      // }
      
      Alert.alert('成功', '图片已保存到相册');
      
      // 返回到相册页面
      navigation.navigate('CameraRollMain', { type: 1 });
    } catch (error) {
      console.error('Save image error:', error);
      Alert.alert('保存失败', '图片保存过程中出现错误');
    } finally {
      setSaving(false);
    }
  };

  // 放弃编辑
  const handleCancel = () => {
    Alert.alert(
      '放弃编辑',
      '确定要放弃当前的编辑吗？',
      [
        { text: '取消', style: 'cancel' },
        { 
          text: '确定', 
          onPress: () => navigation.goBack() 
        }
      ]
    );
  };

  if (isInitializing || !currentImageUri) {
    return (
      <SafeAreaView style={styles.container}>
        <LoadingIndicator loading={true} text="准备编辑器..." fullScreen={true} />
      </SafeAreaView>
    );
  }

  return (
    <SafeAreaView style={styles.container}>
      <CanvasHeader 
        title="图片编辑" 
        onSave={handleSave}
        onCancel={handleCancel}
        saving={isSaving}
      />
      
      <View style={styles.canvasContainer}>
        <EditorCanvas imageUri={currentImageUri} />
      </View>
      
      <MainCategoryTabs 
        activeCategoryId={activeCategoryId}
        onChange={setActiveCategoryId}
      />
      
      <EditorPanels activeCategoryId={activeCategoryId} />
      
      <LoadingIndicator 
        loading={isSaving} 
        text="保存中..." 
        fullScreen={true}
      />
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({

  },

## 画布渲染系统实现

画布渲染系统是编辑器的核心，负责显示图像并应用各种编辑效果。该系统利用React Native Skia进行高性能的图像处理。

### 1. 基础画布组件

```typescript
// src/components/editor/EditorCanvas.tsx
import React, { useState, useEffect } from 'react';
import { View, StyleSheet, Dimensions } from 'react-native';
import { Image } from 'expo-image';
import { useEditorStore } from '../../stores/editorStore';

interface EditorCanvasProps {
  imageUri: string;
}

export default function EditorCanvas({ imageUri }: EditorCanvasProps) {
  const [canvasDimensions, setCanvasDimensions] = useState({ width: 0, height: 0 });
  const screenWidth = Dimensions.get('window').width;
  const screenHeight = Dimensions.get('window').height;
  
  const { setImageSize } = useEditorStore();
  
  // 计算画布尺寸
  useEffect(() => {
    if (imageUri) {
      Image.getSize(imageUri, (width, height) => {
        const aspectRatio = width / height;
        const maxWidth = screenWidth * 0.9;
        const maxHeight = screenHeight * 0.5;
        
        let canvasWidth, canvasHeight;
        
        if (width > height) {
          // 横向图片
          canvasWidth = Math.min(maxWidth, width);
          canvasHeight = canvasWidth / aspectRatio;
          
          if (canvasHeight > maxHeight) {
            canvasHeight = maxHeight;
            canvasWidth = canvasHeight * aspectRatio;
          }
        } else {
          // 纵向图片
          canvasHeight = Math.min(maxHeight, height);
          canvasWidth = canvasHeight * aspectRatio;
          
          if (canvasWidth > maxWidth) {
            canvasWidth = maxWidth;
            canvasHeight = canvasWidth / aspectRatio;
          }
        }
        
        setCanvasDimensions({
          width: canvasWidth,
          height: canvasHeight
        });
        
        // 更新全局状态中的图像尺寸
        setImageSize({ width: canvasWidth, height: canvasHeight });
      });
    }
  }, [imageUri, screenWidth, screenHeight, setImageSize]);
  
  // 根据当前激活的编辑类别渲染不同的画布内容
  const renderCanvasContent = () => {
    return (
      <View style={[styles.canvas, { width: canvasDimensions.width, height: canvasDimensions.height }]}>
        <Image
          source={{ uri: imageUri }}
          style={{ width: '100%', height: '100%' }}
          contentFit="contain"
        />
      </View>
    );
  };
  
  return (
    <View style={styles.container}>
      {canvasDimensions.width > 0 && renderCanvasContent()}
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
  },
  canvas: {
    backgroundColor: 'transparent',
    overflow: 'hidden',
    borderRadius: 8,
    // 添加阴影效果
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.1,
    shadowRadius: 4,
    elevation: 3,
  },
});
```

### 2. 图像处理工具类

```typescript
// src/utils/ImageProcessingUtil.ts
import * as ImageManipulator from 'expo-image-manipulator';
import * as FileSystem from 'expo-file-system';

/**
 * 图像处理工具类
 */
class ImageProcessingUtil {
  /**
   * 调整图像亮度
   * @param imageUri 图像URI
   * @param brightness 亮度值 (-1 到 1)
   */
  async adjustBrightness(imageUri: string, brightness: number): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [],
      {
        brightness: brightness
      }
    );
    return result.uri;
  }

  /**
   * 调整图像对比度
   * @param imageUri 图像URI
   * @param contrast 对比度值 (0 到 2)
   */
  async adjustContrast(imageUri: string, contrast: number): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [],
      {
        contrast: contrast
      }
    );
    return result.uri;
  }

  /**
   * 调整图像饱和度
   * @param imageUri 图像URI
   * @param saturation 饱和度值 (0 到 2)
   */
  async adjustSaturation(imageUri: string, saturation: number): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [],
      {
        saturation: saturation
      }
    );
    return result.uri;
  }

  /**
   * 裁剪图像
   * @param imageUri 图像URI
   * @param crop 裁剪区域 {x, y, width, height}
   */
  async cropImage(
    imageUri: string, 
    crop: { x: number; y: number; width: number; height: number }
  ): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [
        {
          crop: crop
        }
      ],
      { compress: 0.9 }
    );
    return result.uri;
  }

  /**
   * 调整图像尺寸
   * @param imageUri 图像URI
   * @param width 宽度
   * @param height 高度
   */
  async resizeImage(imageUri: string, width: number, height: number): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [
        {
          resize: {
            width,
            height
          }
        }
      ],
      { compress: 0.9 }
    );
    return result.uri;
  }

  /**
   * 旋转图像
   * @param imageUri 图像URI
   * @param degrees 旋转角度
   */
  async rotateImage(imageUri: string, degrees: number): Promise<string> {
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      [
        {
          rotate: degrees
        }
      ],
      { compress: 0.9 }
    );
    return result.uri;
  }

  /**
   * 翻转图像
   * @param imageUri 图像URI
   * @param horizontal 是否水平翻转
   * @param vertical 是否垂直翻转
   */
  async flipImage(imageUri: string, horizontal: boolean, vertical: boolean): Promise<string> {
    const actions = [];
    
    if (horizontal) {
      actions.push({ flip: { horizontal: true } });
    }
    
    if (vertical) {
      actions.push({ flip: { vertical: true } });
    }
    
    if (actions.length === 0) {
      return imageUri;
    }
    
    const result = await ImageManipulator.manipulateAsync(
      imageUri,
      actions,
      { compress: 0.9 }
    );
    return result.uri;
  }

  /**
   * 将图像保存为临时文件
   * @param imageUri 图像URI
   * @param filename 文件名
   */
  async saveToTempFile(imageUri: string, filename: string): Promise<string> {
    const tempDir = FileSystem.cacheDirectory + 'temp/';
    const tempPath = tempDir + filename;
    
    // 确保临时目录存在
    const dirInfo = await FileSystem.getInfoAsync(tempDir);
    if (!dirInfo.exists) {
      await FileSystem.makeDirectoryAsync(tempDir, { intermediates: true });
    }
    
    // 将文件复制到临时目录
    await FileSystem.copyAsync({
      from: imageUri,
      to: tempPath
    });
    
    return tempPath;
  }

  /**
   * 获取图像信息
   * @param imageUri 图像URI
   */
  async getImageInfo(imageUri: string): Promise<{ width: number; height: number }> {
    return new Promise((resolve, reject) => {
      Image.getSize(
        imageUri,
        (width, height) => {
          resolve({ width, height });
        },
        (error) => {
          reject(error);
        }
      );
    });
  }
}

export default new ImageProcessingUtil();
``` 

## 编辑器状态管理实现

使用Zustand作为状态管理方案，替代原有的Redux/Rematch。

### 1. 编辑器基础状态

```typescript
// src/stores/editorStore.ts
import { create } from 'zustand';
import { MainCategoryType } from '../types/editorTypes';

interface EditorState {
  // 主分类状态
  activeCategoryId: number;
  setActiveCategoryId: (id: number) => void;
  
  // 图像状态
  currentImageUri: string | null;
  imageSize: { width: number; height: number } | null;
  setCurrentImageUri: (uri: string | null) => void;
  setImageSize: (size: { width: number; height: number } | null) => void;
  
  // 编辑历史
  editHistory: string[];
  currentEditIndex: number;
  addHistoryItem: (uri: string) => void;
  undo: () => void;
  redo: () => void;
  clearHistory: () => void;
  
  // 保存状态
  isSaving: boolean;
  setSaving: (saving: boolean) => void;
}

export const useEditorStore = create<EditorState>((set, get) => ({
  // 主分类状态
  activeCategoryId: MainCategoryType.FILTER,
  setActiveCategoryId: (id) => set({ activeCategoryId: id }),
  
  // 图像状态
  currentImageUri: null,
  imageSize: null,
  setCurrentImageUri: (uri) => set({ currentImageUri: uri }),
  setImageSize: (size) => set({ imageSize: size }),
  
  // 编辑历史
  editHistory: [],
  currentEditIndex: -1,
  addHistoryItem: (uri) => set((state) => {
    // 丢弃当前索引之后的历史记录
    const newHistory = state.editHistory.slice(0, state.currentEditIndex + 1);
    return {
      editHistory: [...newHistory, uri],
      currentEditIndex: newHistory.length
    };
  }),
  undo: () => set((state) => {
    if (state.currentEditIndex > 0) {
      return {
        currentEditIndex: state.currentEditIndex - 1,
        currentImageUri: state.editHistory[state.currentEditIndex - 1]
      };
    }
    return state;
  }),
  redo: () => set((state) => {
    if (state.currentEditIndex < state.editHistory.length - 1) {
      return {
        currentEditIndex: state.currentEditIndex + 1,
        currentImageUri: state.editHistory[state.currentEditIndex + 1]
      };
    }
    return state;
  }),
  clearHistory: () => set({ editHistory: [], currentEditIndex: -1 }),
  
  // 保存状态
  isSaving: false,
  setSaving: (saving) => set({ isSaving: saving }),
}));
```

## 模块间数据流

编辑器各组件之间的数据流如下：

1. **用户选择图片** → **加载到编辑器主页面**
   - `CameraRollMain` → `EditorHome`
   - 通过路由参数传递选中的图片URI

2. **用户选择编辑类型** → **显示对应面板**
   - `MainCategoryTabs` → `EditorPanels`
   - 通过Zustand状态管理传递活动分类ID

3. **用户进行编辑操作** → **更新画布显示**
   - 各编辑面板(如`FilterPanel`) → `EditorCanvas`
   - 通过Zustand状态管理传递编辑参数和结果

4. **用户保存编辑结果** → **返回相册页面**
   - `EditorHome` → `CameraRollMain`
   - 通过路由导航完成

## 编辑器扩展性设计

编辑器模块采用了高度模块化的设计，便于后续扩展新功能：

1. **模块化面板系统**：
   - 每个编辑功能都是独立的面板
   - 可以轻松添加新的编辑功能面板

2. **插件式渲染系统**：
   - 渲染层使用组合模式
   - 可以添加新的渲染效果和处理器

3. **统一的状态管理**：
   - 所有状态集中在Zustand存储
   - 功能模块可以共享状态或保持独立

4. **通用的图像处理工具**：
   - 基础图像处理功能封装在工具类中
   - 新功能可复用现有工具类方法
