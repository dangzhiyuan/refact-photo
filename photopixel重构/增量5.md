# 模板模块实现

模板模块允许用户将预设的专业设计模板应用到图像上，实现一键美化功能。该模块包含以下核心功能：

1. 模板资源管理和展示
2. 模板应用到图像
3. 模板参数调整
4. 预览和效果对比

## 模块结构

模板模块由以下主要组件构成：

```
template/
├── TemplatePanel.tsx           // 模板面板主容器
├── TemplateList.tsx            // 模板列表组件
├── TemplateCategory.tsx        // 模板分类组件
├── TemplatePreview.tsx         // 模板预览组件
├── TemplateApply.tsx           // 模板应用组件
├── TemplateParamAdjust.tsx     // 模板参数调整组件
└── TemplateCanvas.tsx          // 模板渲染画布组件
```

## 模板状态管理

模板功能需要专门的状态管理，用于跟踪当前选择的模板和相关参数。

```typescript
// src/stores/templateStore.ts
import { create } from 'zustand';

// 模板分类
export enum TemplateCategoryType {
  BASIC = 0,
  FRAME = 1,
  TEXT = 2,
  FESTIVAL = 3,
  SEASON = 4
}

// 模板参数类型
export enum TemplateParamType {
  INTENSITY = 0,
  COLOR = 1,
  OPACITY = 2,
  POSITION = 3,
  SIZE = 4
}

// 模板参数
export interface TemplateParam {
  id: string;
  name: string;
  type: TemplateParamType;
  value: any;
  min?: number;
  max?: number;
  defaultValue: any;
}

// 模板对象
export interface Template {
  id: string;
  name: string;
  previewUri: string;
  category: TemplateCategoryType;
  description: string;
  params: TemplateParam[];
  applyFn?: (imageUri: string, params: TemplateParam[]) => Promise<string>;
}

interface TemplateState {
  // 模板列表和选择
  templates: Template[];
  selectedTemplateId: string | null;
  
  // 模板操作
  setSelectedTemplateId: (id: string | null) => void;
  updateTemplateParam: (templateId: string, paramId: string, value: any) => void;
  resetTemplateParams: (templateId: string) => void;
  
  // 当前分类
  currentCategoryType: TemplateCategoryType;
  setCurrentCategoryType: (type: TemplateCategoryType) => void;
  
  // 应用状态
  isApplying: boolean;
  setIsApplying: (applying: boolean) => void;
  
  // 预览
  previewUri: string | null;
  setPreviewUri: (uri: string | null) => void;
}

export const useTemplateStore = create<TemplateState>((set, get) => ({
  // 模板列表和选择
  templates: [],
  selectedTemplateId: null,
  
  // 模板操作
  setSelectedTemplateId: (id) => set({ selectedTemplateId: id }),
  
  updateTemplateParam: (templateId, paramId, value) => set(state => {
    const templates = state.templates.map(template => {
      if (template.id === templateId) {
        return {
          ...template,
          params: template.params.map(param => 
            param.id === paramId ? { ...param, value } : param
          )
        };
      }
      return template;
    });
    
    return { templates };
  }),
  
  resetTemplateParams: (templateId) => set(state => {
    const templates = state.templates.map(template => {
      if (template.id === templateId) {
        return {
          ...template,
          params: template.params.map(param => 
            ({ ...param, value: param.defaultValue })
          )
        };
      }
      return template;
    });
    
    return { templates };
  }),
  
  // 当前分类
  currentCategoryType: TemplateCategoryType.BASIC,
  setCurrentCategoryType: (type) => set({ currentCategoryType: type }),
  
  // 应用状态
  isApplying: false,
  setIsApplying: (applying) => set({ isApplying: applying }),
  
  // 预览
  previewUri: null,
  setPreviewUri: (uri) => set({ previewUri: uri }),
}));
```

## 模板参数调整组件

允许用户调整所选模板的参数。

```typescript
// src/components/template/TemplateParamAdjust.tsx
import React from 'react';
import {
  View,
  StyleSheet,
  Text,
  TouchableOpacity,
  ScrollView,
  TextInput,
  ActivityIndicator
} from 'react-native';
import { useTemplateStore, TemplateParamType } from '../../stores/templateStore';
import Slider from '@react-native-community/slider';
import { Ionicons } from '@expo/vector-icons';
import { useEditorStore } from '../../stores/editorStore';
import ColorPicker from '../common/ColorPicker';

interface TemplateParamAdjustProps {
  templateId: string;
}

export default function TemplateParamAdjust({ templateId }: TemplateParamAdjustProps) {
  const { 
    templates, 
    updateTemplateParam, 
    resetTemplateParams,
    setSelectedTemplateId,
    isApplying,
    setIsApplying,
    setPreviewUri
  } = useTemplateStore();
  
  const { currentImageUri, setCurrentImageUri } = useEditorStore();
  
  // 获取当前选中的模板
  const selectedTemplate = templates.find(t => t.id === templateId);
  
  if (!selectedTemplate) {
    return (
      <View style={styles.errorContainer}>
        <Text style={styles.errorText}>未找到选中的模板</Text>
        <TouchableOpacity
          style={styles.backButton}
          onPress={() => setSelectedTemplateId(null)}
        >
          <Text style={styles.backButtonText}>返回列表</Text>
        </TouchableOpacity>
      </View>
    );
  }
  
  // 处理参数修改
  const handleParamChange = (paramId: string, value: any) => {
    updateTemplateParam(templateId, paramId, value);
  };
  
  // 处理重置参数
  const handleResetParams = () => {
    resetTemplateParams(templateId);
  };
  
  // 处理应用模板
  const handleApplyTemplate = async () => {
    if (!currentImageUri || !selectedTemplate.applyFn) return;
    
    try {
      setIsApplying(true);
      
      // 调用模板的应用函数
      const resultUri = await selectedTemplate.applyFn(currentImageUri, selectedTemplate.params);
      
      // 更新当前图像
      setCurrentImageUri(resultUri);
      
      // 清除预览
      setPreviewUri(null);
      
      // 返回到模板列表
      setSelectedTemplateId(null);
    } catch (error) {
      console.error('Template application error:', error);
    } finally {
      setIsApplying(false);
    }
  };
  
  // 处理取消
  const handleCancel = () => {
    setSelectedTemplateId(null);
  };
  
  // 处理预览
  const handlePreview = async () => {
    if (!currentImageUri || !selectedTemplate.applyFn) return;
    
    try {
      setIsApplying(true);
      
      // 调用模板的应用函数获取预览
      const previewUri = await selectedTemplate.applyFn(currentImageUri, selectedTemplate.params);
      
      // 设置预览
      setPreviewUri(previewUri);
    } catch (error) {
      console.error('Template preview error:', error);
    } finally {
      setIsApplying(false);
    }
  };
  
  // 根据参数类型渲染不同的控件
  const renderParamControl = (param: any) => {
    switch (param.type) {
      case TemplateParamType.INTENSITY:
      case TemplateParamType.OPACITY:
      case TemplateParamType.SIZE:
        return (
          <View style={styles.sliderContainer}>
            <View style={styles.sliderLabels}>
              <Text style={styles.paramName}>{param.name}</Text>
              <Text style={styles.paramValue}>{typeof param.value === 'number' ? param.value.toFixed(2) : param.value}</Text>
            </View>
            <Slider
              style={styles.slider}
              minimumValue={param.min}
              maximumValue={param.max}
              value={param.value}
              onValueChange={(value) => handleParamChange(param.id, value)}
              minimumTrackTintColor="#3498db"
              maximumTrackTintColor="#bdc3c7"
              thumbTintColor="#3498db"
            />
          </View>
        );
        
      case TemplateParamType.COLOR:
        return (
          <View style={styles.colorContainer}>
            <Text style={styles.paramName}>{param.name}</Text>
            <ColorPicker
              color={param.value}
              onChange={(color) => handleParamChange(param.id, color)}
            />
          </View>
        );
        
      case TemplateParamType.TEXT:
        return (
          <View style={styles.textContainer}>
            <Text style={styles.paramName}>{param.name}</Text>
            <TextInput
              style={styles.textInput}
              value={param.value}

              />
              <Text style={styles.positionLabel}>Y:</Text>
              <Slider
                style={styles.positionSlider}
                minimumValue={0}
                maximumValue={1}

                maximumTrackTintColor="#bdc3c7"
                thumbTintColor="#3498db"
              />
            </View>
          </View>
        );
        
      default:
        return (
          <Text style={styles.unsupportedParam}>不支持的参数类型: {param.type}</Text>
        );
    }
  };

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.templateName}>{selectedTemplate.name}</Text>
        <TouchableOpacity
          style={styles.resetButton}
          onPress={handleResetParams}
        >
          <Ionicons name="refresh" size={16} color="#3498db" />
          <Text style={styles.resetText}>重置</Text>
        </TouchableOpacity>
      </View>
      
      <ScrollView style={styles.paramsContainer}>
        {selectedTemplate.params.map((param) => (
          <View key={param.id} style={styles.paramContainer}>
            {renderParamControl(param)}
          </View>
        ))}
      </ScrollView>
      
      <View style={styles.actionButtons}>
        <TouchableOpacity
          style={styles.cancelButton}
          onPress={handleCancel}
          disabled={isApplying}
        >
          <Text style={styles.cancelButtonText}>取消</Text>
        </TouchableOpacity>
        
        <TouchableOpacity
          style={styles.previewButton}
          onPress={handlePreview}
          disabled={isApplying}
        >
          <Text style={styles.previewButtonText}>预览</Text>
        </TouchableOpacity>
        
        <TouchableOpacity
          style={styles.applyButton}
          onPress={handleApplyTemplate}
          disabled={isApplying}
        >
          {isApplying ? (
            <ActivityIndicator size="small" color="#fff" />
          ) : (
            <Text style={styles.applyButtonText}>应用</Text>
          )}
        </TouchableOpacity>
      </View>
    </View>
  );
}
```

模板模块通过以下方式集成到编辑器中：

1. 当用户切换到模板编辑类别时，显示模板面板：


2. 用户可以浏览不同类别的模板，查看模板预览图，并选择应用到当前图像。

3. 选择模板后，用户可以调整模板参数，如强度、颜色等，以自定义模板效果。

4. 调整参数后，用户可以预览效果，或直接应用模板到当前图像。

### 模板模块的特性

模板模块具有以下特点：

1. **分类管理**：模板按类别进行组织和展示，包括基础、相框、文字、节日和季节等分类，便于用户快速找到所需模板。

2. **参数调整**：模板提供了多种可调整的参数，包括：
   - 强度：控制模板效果的强弱
   - 颜色：调整模板中颜色元素的颜色
   - 大小：调整模板元素的大小
   - 透明度：控制模板元素的透明度
   - 位置：调整模板元素在图像上的位置
   - 文字：编辑模板中的文字内容

3. **实时预览**：用户可以在应用模板前预览效果，确保得到期望的结果。

4. **一键应用**：提供简单的应用按钮，将编辑好的模板效果应用到图像上。

### 模板应用流程

模板应用的整体流程如下：

1. 用户在模板分类中选择一个模板类别
2. 浏览该类别中的模板并选择一个感兴趣的模板
3. 查看并调整模板参数，如强度、颜色等
4. 点击"预览"按钮查看效果
5. 满意后点击"应用"按钮将模板应用到图像
6. 模板应用后，可以继续进行其他编辑操作或保存图像

这种实现让用户可以快速美化照片，无需复杂的手动编辑，同时也保留了自定义模板效果的灵活性。
